ขั้นตอนการ Upload ขึ้น GitHub และเปิดดูผ่าน Website (GitHub Pages)

โปรเจกต์นี้ได้รับการจัดเตรียม Source Code แบบ Static Web พร้อมไฟล์ PDF ทั้งหมดไว้เรียบร้อยแล้ว สามารถอัปโหลดขึ้น GitHub และเปิดใช้งาน GitHub Pages เพื่อเข้าชมผ่านเบราว์เซอร์ได้ทันที

1
สร้าง Repository บน GitHub
เข้าสู่เว็บไซต์ GitHub แล้วสร้าง Repository ใหม่ (เช่นชื่อ ai-assignments-showcase) เลือกเป็น Public
2
เชื่อมโยงและ Push Source Code
รันคำสั่งเชื่อมโยง Remote Repository และ Push โค้ดขึ้นไป:
git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
git branch -M main
git push -u origin main
3
เปิดใช้งาน GitHub Pages
ไปที่เมนู Settings ของ Repo > เลือก Pages (เมนูด้านซ้าย) > ตรงส่วน Branch ให้เลือก main และโฟลเดอร์ / (root) > กด Save
4
เข้าชมเว็บไซต์ได้ทันที!
หลังจากกด Save รอระบบ Build ประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์สำหรับเข้าดูผลงาน เช่น:
https://<YOUR_USERNAME>.github.io/<REPO_NAME>/
